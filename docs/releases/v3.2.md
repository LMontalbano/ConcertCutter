ConcertCutter 3.2 adds a fully bilingual interface and makes the application accessible to English-speaking users.

- The interface is now available in English and French, including analysis, editing, export, error messages and native file dialogs.
- Automatic language selection follows the Windows display language: French systems use French, while all other systems use English.
- A language selector in **Options** applies changes immediately, without restarting the application or losing current work.
- A manual language choice is remembered across launches and can be reset to automatic detection at any time.
- The English user guide and README cover installation, the complete workflow, shortcuts, export formats and known limitations.
- Track titles, exported filenames and existing projects remain unchanged when switching languages.

Automated tests cover language detection, saved preferences, translated server responses and the localized web interface.

Download **ConcertCutter.exe** from this release's assets. The executable is self-contained for Windows 10 and 11.
