ConcertCutter 3.4 fixes image fade durations in video exports.

- The selected duration, from 0 to 60 seconds, is now applied without being silently capped at four seconds.
- A value of 0 seconds now produces a hard cut instead of restoring the default fade.
- In slideshow mode, each image remains fully visible for eight seconds before the selected fade leads into the next one.
- Tests measure the frames that are actually rendered to prevent another timing regression.

This version can be installed directly from ConcertCutter 3.3 through automatic updates.

Download **ConcertCutter.exe** and **SHA256SUMS.txt** from this release's assets.
