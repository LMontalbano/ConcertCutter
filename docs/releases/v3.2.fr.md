[English](v3.2.md) · Français

ConcertCutter 3.2 ajoute une interface entièrement bilingue et rend l'application accessible aux utilisateurs anglophones.

- L'interface est désormais disponible en anglais et en français, y compris pour l'analyse, l'édition, l'export, les messages d'erreur et les boîtes de dialogue natives.
- La sélection automatique suit la langue d'affichage de Windows : les systèmes en français utilisent le français, tous les autres utilisent l'anglais.
- Un sélecteur de langue dans les **Options** applique le changement immédiatement, sans redémarrer l'application ni perdre le travail en cours.
- Le choix manuel est conservé entre les lancements et peut être réinitialisé à la détection automatique à tout moment.
- Le guide utilisateur et le README anglais couvrent l'installation, le parcours complet, les raccourcis, les formats d'export et les limites connues.
- Les titres des morceaux, les noms des fichiers exportés et les projets existants restent inchangés lors d'un changement de langue.

Des tests automatisés couvrent la détection de la langue, les préférences enregistrées, les réponses traduites du serveur et l'interface web localisée.

Téléchargez **ConcertCutter.exe** dans les fichiers de cette release. L'exécutable est autonome pour Windows 10 et 11.
