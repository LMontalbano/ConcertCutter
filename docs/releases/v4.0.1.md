ConcertCutter 4.0.1 addresses feedback on the video montage editor introduced in 4.0.0.

- Images in the source library and timeline are shown in full at their original proportions, even with many sources. Trim handles no longer cover thumbnails.
- The per-image “+” button is removed from the library, and the remove control is less prominent.
- Clicking outside the montage window no longer closes it.
- “Resume a project…” opens the saved projects folder directly.
- Native file pickers use the current pywebview API without deprecation warnings.

Download **ConcertCutter.exe** and **SHA256SUMS.txt** from this release's assets.
