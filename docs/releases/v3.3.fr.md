ConcertCutter 3.3 peut désormais rechercher et installer ses mises à jour stables.

- Une vérification non bloquante au lancement annonce les nouvelles versions dans une bannière.
- Le téléchargement ne commence qu'après confirmation et son empreinte SHA-256 est contrôlée avant installation.
- ConcertCutter redémarre automatiquement et reprend le travail en cours après le remplacement de l'exécutable portable.
- En cas d'échec, l'ancienne version reste disponible et le site officiel permet de terminer la mise à jour manuellement.
- Les vérifications automatiques peuvent être désactivées dans **Options**, où une recherche manuelle reste disponible.

Cette première version équipée de l'updater doit encore être téléchargée manuellement. Les versions suivantes pourront être installées directement depuis l'application.

Téléchargez **ConcertCutter.exe** et **SHA256SUMS.txt** dans les fichiers de cette release.
