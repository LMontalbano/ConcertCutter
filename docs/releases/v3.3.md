ConcertCutter 3.3 can now check for and install stable updates.

- A non-blocking launch check announces new versions in a persistent banner.
- Downloads start only after confirmation and their SHA-256 checksum is verified before installation.
- ConcertCutter restarts automatically and resumes the current project after replacing the portable executable.
- If anything fails, the previous version remains available and the official website provides a manual update path.
- Automatic checks can be disabled in **Options**, where a manual check remains available.

This first updater-enabled release must still be downloaded manually. Later versions can be installed directly from the application.

Download **ConcertCutter.exe** and **SHA256SUMS.txt** from this release's assets.
