ConcertCutter 3.4 corrige la durée du fondu entre les images des exports vidéo.

- La durée choisie, de 0 à 60 secondes, est maintenant appliquée sans être silencieusement ramenée à quatre secondes.
- Une valeur de 0 seconde produit bien une coupe franche au lieu de reprendre le fondu par défaut.
- Dans le diaporama, chaque image reste pleinement affichée huit secondes avant que le fondu choisi l'amène à la suivante.
- Des tests mesurent les images effectivement rendues afin d'éviter une nouvelle régression de la chronologie.

Cette version peut être installée directement depuis ConcertCutter 3.3 grâce à la mise à jour automatique.

Téléchargez **ConcertCutter.exe** et **SHA256SUMS.txt** dans les fichiers de cette release.
